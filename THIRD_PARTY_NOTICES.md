## Rebuilding the local vendor directory

Install the exact versions from `package-lock.json`, then copy the production assets and license files:

```bash
npm ci
npm run vendor
```

## Integrity manifest

`vendor/manifest.json` lists the exact package version, byte size, and SHA-256 checksum of every bundled production asset and license file. It is regenerated by `npm run vendor`.
